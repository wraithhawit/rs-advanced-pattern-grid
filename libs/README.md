# Local dependency jars

The jars here are compile-only dependencies and are ignored by Git; this repository does not
redistribute them. Copy them from a Minecraft instance's `mods` folder:

- `refinedstorage-neoforge-2.0.9.jar` (required)
- `refinedfluidsubstitution-neoforge-1.21.1-2.0.0.jar` (optional at runtime, needed to compile)

`dependencies.sha256` records the exact jars the build was made against.
- `emi-1.1.24+1.21.1+neoforge.jar` (optional at runtime, needed to compile the recipe-tree button)
- `rsmbac-0.11.6.jar` (optional at runtime, needed to compile the rsmbac placement)
